# Simple Interest Calculator

A Bash script that calculates simple interest from user input.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal: the amount of money (e.g. 1000)
- Rate of interest: annual percentage (e.g. 5)
- Time period: in years (e.g. 2)

## Usage
```bash
bash simple-interest.sh
```

## Example
Principal: 1000, Rate: 5, Time: 2 → Simple interest = 100
